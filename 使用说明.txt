AutoFillFace 使用说明
======================

一、首次使用
------------
1. 打开 dist 文件夹里的 AutoFillFace.exe（首次启动约 3-5 秒，要解压内置模型）。
2. 程序启动后停在右下角托盘，主窗口是深色界面，三个标签页：密码库 / 人脸 / 设置。

二、先注册人脸（必须做一次）
----------------------------
1. 切到"人脸"标签页。
2. 点"开始注册（摄像头采集）"，正对摄像头，保持光线充足。
3. 等几秒，日志区显示"注册成功：已保存 N 帧人脸模板"。
4. 如果提示"未检测到人脸"，调整光线或人离摄像头近一点重试。

三、给每个登录页添加一条记录
----------------------------
1. 先在浏览器里打开你要存的网站登录页。
2. 回到 AutoFillFace，点"密码库"标签 → 点"新增"。
3. 弹出的向导会截当前屏幕：
   - 在预览图上点一下【用户名输入框】的位置（出现红点）
   - 再点一下【密码输入框】的位置（出现蓝点）
   - 如果页面会变化（比如展开登录框、切换账号密码 tab），点"屏幕截图"按钮，窗口自动最小化，切到那个页面再截一张，回来后继续点坐标
   - 填服务名（必填）、网址、用户名、密码
   - 自定义宏可以留空，需要额外操作再写（格式见下文）
4. 点"保存此服务"。

四、日常使用
------------
1. 在任意网站登录页（必须是你刚才存过截图的那个页面或相似页面）。
2. 按 Ctrl+Alt+M。
3. 屏幕顶部会出现动画：黑色圆点变形 → 摄像头采集 → 如果是本人就播放绿色扫描动画。
4. 验证通过后自动帮你点用户名框、填用户名、点密码框、填密码。

五、自定义宏格式
----------------
每行一条命令：
  click 0.35,0.50    点击比例坐标（0~1，相对于屏幕宽高）
  type 你要输入的文字  模拟键盘输入
  key ENTER          按回车键（也支持 TAB/ESC/SPACE/BACKSPACE）
  sleep 0.5          等待 0.5 秒

六、常见问题
------------
Q: 按了热键没反应？
A: 看主界面日志区最后一行。如果卡在"正在打开摄像头"，可能是摄像头被别的程序占用。

Q: 识别不了我的脸？
A: 去"设置"标签把"人脸相似度阈值"调低（比如 0.45），或重新注册人脸。

Q: 填错位置了？
A: 在密码库里选中那条记录，点"编辑"可以改账号密码；坐标需要重新新增一条记录（先删除旧的）。

Q: 密码存在哪？安全吗？
A: 加密存在 EXE 同目录的 vault.bin，用 Windows DPAPI 加密，只有你当前 Windows 用户能解开，拷到别的电脑没用。

Q: 程序关了热键还能用吗？
A: 不能，必须开着 AutoFillFace.exe。要开机自启就把它的快捷方式放进启动文件夹。
